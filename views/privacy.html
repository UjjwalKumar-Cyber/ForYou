Privacy

ForyoU is a private beta for memories, feelings, letters, and time capsules. Your memories belong to you.

What ForyoU Saves

ForyoU stores your username, display name, password hash, profile settings, profile photo URL or data, messages, media metadata, timestamps, read state, reactions, saved/starred state, and popup alert status.

For signed-in accounts, ForyoU also stores security activity such as login time, logout time, last seen, online state, failed login attempts, approximate IP-based location, browser, operating system, screen size, language, timezone, and device type.

What ForyoU Does Not Save

ForyoU does not collect contacts, SMS, calls, IMEI, private device identifiers, or exact GPS location. The public secret note page does not ask for sender email or login details.

Admin Visibility

The ultimate admin dashboard can see transparent moderation and security information for signed-in accounts, including true online state. Normal users still cannot see anonymous users as active.

Encryption Status

Messages are private inside ForyoU and protected by account access, but they are not end-to-end encrypted yet. Do not use this beta for highly sensitive information.

Deletion Requests

Private testers can ask the admin to delete their account, messages, media, or activity records.
