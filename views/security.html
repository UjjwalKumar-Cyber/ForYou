Security

ForyoU uses practical beta safeguards so testers can use the site calmly while the product grows.

Account Protection

Passwords are stored as hashes, sessions use secure cookies in production, and protected APIs re-check whether an account is active before allowing access.

Abuse Protection

Login, message, admin, and activity APIs are rate limited. Admins can block, suspend, or reactivate accounts and these actions are logged.

Media Safety

Uploads are limited by type and size. Images are compressed before storage when possible, and Cloudinary can be used so the database stores URLs instead of large files.

Private Tester Reminder

ForyoU is not end-to-end encrypted yet. Avoid sending secrets that require stronger protection until that feature exists.
